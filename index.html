איך שומרים את כל ההיסטוריה של הפרויקט, מגבים אותו בענן ועובדים עליו יחד עם חברים לצוות. צפו בסרטון, עברו על המצגת, ונסו בעצמכם.

שליטה מלאה עם Git ו-GitHub.

המצגת

אפשר לדפדף כאן או להוריד ולפתוח במסך מלא.

לא רואים את המצגת בטלפון? פתחו אותה בחלון נפרד. פתיחה / הורדה

מחזור העבודה – 4 צעדים

כל עבודה ב-Git חוזרת על אותם ארבעה צעדים.

  1. עורכים

    משנים קבצים בתיקיית הפרויקט.

  2. בוחרים

    מה ייכנס לשמירה הבאה.

    git add .

  3. שומרים

    נקודת שמירה עם הסבר.

    git commit -m "..."

  4. מעלים

    שולחים לענן, ל-GitHub.

    git push

דף פקודות

כדאי להדפיס ולתלות ליד המחשב.

פקודהמה היא עושה
git --versionבודק ש-Git מותקן
git config --global user.name ".."מגדיר שם (וגם user.email לאימייל)
git initהופך תיקייה רגילה למאגר
git clone <url>מוריד מאגר מ-GitHub למחשב
git statusמה השתנה?
git add .מכין את כל השינויים לשמירה
git commit -m ".."יוצר נקודת שמירה
git pushמעלה ל-GitHub
git pullמוריד שינויים חדשים מ-GitHub
git log --onelineהיסטוריית נקודות השמירה
git branch <name>יוצר ענף חדש
git switch <name>עובר לענף
git merge <name>ממזג ענף לענף הנוכחי
git diffמה בדיוק השתנה בכל שורה

קבצים קטנים

GitHub חוסם קבצים מעל 100MB. דרך הדפדפן אפשר להעלות עד 25MB.

קודם pull

קיבלתם rejected? הריצו git pull ואחר כך git push.
